ZERO COMPANY MANDALORIAN WARDROBE v0.4.2
Steam build 24874058

REQUIRES
UE4SS for Star Wars Zero Company v1.0 must already be installed.

INSTALL OR UPDATE
1. Close the game.
2. In Steam, right-click Star Wars: Zero Company, choose Manage, then Browse local files.
3. Open SWZeroCompany, then Binaries, then Win64.
4. Drag the ue4ss folder beside this file into that Win64 folder.
5. Allow Windows to merge folders and replace the older mod file when updating.
6. Launch the game normally.

No PowerShell, command prompt, or mods.txt editing is required.

The final files should be:
SWZeroCompany\Binaries\Win64\ue4ss\Mods\ZeroCompanyMandoWardrobe\enabled.txt
SWZeroCompany\Binaries\Win64\ue4ss\Mods\ZeroCompanyMandoWardrobe\dlls\main.dll

REMOVE
Equip stock wardrobe parts, close the game, then delete:
SWZeroCompany\Binaries\Win64\ue4ss\Mods\ZeroCompanyMandoWardrobe

For full documentation and source code:
https://github.com/Sternab/ZeroCompanyMandoWardrobe
